# ✦ ASTRION — Explorando o Universo

> Uma jornada interativa pelo Sistema Solar.

## 🌌 Sobre o projeto

O **ASTRION** é um projeto acadêmico educacional desenvolvido com o objetivo de apresentar o Sistema Solar de forma interativa, visual e acessível.

A proposta é permitir que o usuário explore os planetas e descubra informações sobre suas características, composição, curiosidades e referências culturais relacionadas ao espaço.

Mais do que apresentar informações, o projeto busca transformar o aprendizado de Astronomia em uma experiência mais visual e envolvente.

---

## 🪐 O que é possível encontrar?

No ASTRION, o usuário pode:

- ✦ Explorar os planetas do Sistema Solar;
- ✦ Visualizar os planetas em uma representação interativa;
- ✦ Conhecer características de cada planeta;
- ✦ Descobrir curiosidades;
- ✦ Aprender sobre composição e características físicas;
- ✦ Encontrar indicações de filmes e livros relacionados ao espaço;
- ✦ Navegar por uma interface visual inspirada no universo;
- ✦ Interagir com os planetas presentes no Sistema Solar.

---

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais para o desenvolvimento web:

- **HTML5** — estrutura da página;
- **CSS3** — estilização, animações e layout;
- **JavaScript** — interatividade e funcionamento dos elementos.

---

## 🎓 Objetivo educacional

O ASTRION foi desenvolvido como um **projeto acadêmico educacional**, buscando utilizar a tecnologia como ferramenta de apoio à aprendizagem.

Através de uma abordagem interativa, o projeto procura tornar conteúdos relacionados à Astronomia mais atrativos e facilitar a exploração das informações pelo usuário.

---

## ✦ Interface

A interface foi desenvolvida com uma estética inspirada no espaço, utilizando:

- Fundo estrelado;
- Representação visual do Sistema Solar;
- Animações;
- Elementos interativos;
- Cards informativos;
- Design responsivo.

---

## 📚 Público-alvo

O projeto pode ser utilizado principalmente por:

- Estudantes;
- Professores;
- Pessoas interessadas em Astronomia;
- Usuários que desejam conhecer melhor o Sistema Solar.
