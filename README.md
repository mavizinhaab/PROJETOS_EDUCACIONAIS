# Projetos Educacionais

Repositório destinado ao desenvolvimento e registro de projetos voltados à
educação, ao ensino e à aprendizagem.

Os projetos aqui reunidos exploram diferentes possibilidades de utilização
da tecnologia como recurso educacional, especialmente no contexto do ensino
de Física.

### Áreas de interesse

`Educação` · `Ensino de Física` · `Tecnologia Educacional` · `Desenvolvimento Web`
