# 🧪 O Último Experimento

> Um jogo de investigação, lógica e Física ambientado em um laboratório
> onde algo deu muito errado.

---

## 🌌 Sobre o jogo

**O Último Experimento** é um jogo de investigação e resolução de enigmas
ambientado em um laboratório científico.

O jogador assume o papel de um investigador que precisa descobrir o que
aconteceu com o último experimento realizado no laboratório.

Para conseguir avançar, será necessário observar o ambiente, encontrar
pistas, interpretar informações, resolver problemas e descobrir a sequência
correta dos acontecimentos.

O jogo mistura elementos de:

- 🔬 Investigação;
- 🧪 Ciência;
- ⚛️ Física;
- 🧩 Raciocínio lógico;
- 🔐 Enigmas;
- 💻 Tecnologia;
- 📖 Narrativa.

---

# 📖 História

Durante anos, um laboratório secreto realizou pesquisas relacionadas a
fenômenos físicos ainda pouco compreendidos.

Tudo parecia funcionar normalmente até a realização de um experimento
conhecido apenas como:

## "Experimento 07"

Na noite em que o experimento foi realizado, os sistemas do laboratório
registraram uma série de acontecimentos anormais.

As câmeras foram desligadas.

O sistema principal entrou em modo de emergência.

Os registros do computador foram parcialmente apagados.

E o pesquisador responsável pelo experimento desapareceu.

Quando o laboratório foi encontrado, não havia ninguém no local.

Apenas equipamentos ligados, documentos espalhados e uma série de pistas
deixadas aparentemente de propósito.

Agora, cabe ao jogador entrar no laboratório e descobrir:

> **O que aconteceu naquela noite?**

---

# 🎯 Objetivo

O principal objetivo do jogo é descobrir o que aconteceu durante o
**Experimento 07**.

Para isso, o jogador deverá:

1. Explorar o laboratório;
2. Observar os objetos disponíveis;
3. Encontrar pistas;
4. Resolver os enigmas;
5. Utilizar os conhecimentos de Física;
6. Descobrir códigos;
7. Seguir a sequência correta;
8. Encontrar a resposta final.

---

# 🎮 Como jogar

## 1. Tela inicial

Ao iniciar o jogo, o jogador encontrará uma tela representando o espaço.

Nessa tela estão disponíveis:

- O título do jogo;
- Uma breve introdução;
- O botão **"Iniciar Experimento"**.

Clique no botão para entrar no laboratório.

---

# 🧪 2. O laboratório

Depois de iniciar o jogo, o ambiente muda completamente.

O jogador entra no laboratório onde estão espalhados diferentes objetos.

Entre eles estão:

- 🖥️ Computador;
- 📋 Quadro;
- 🧪 Frascos;
- 📄 Documentos;
- 🔐 Cofre;
- 🚪 Porta de segurança;
- 🕐 Relógio;
- 🧰 Equipamentos.

Nem todos os objetos precisam ser utilizados imediatamente.

A observação é uma das principais ferramentas do jogador.

---

# 🔎 3. Como funcionam as pistas

Cada objeto pode apresentar uma informação importante.

Algumas pistas fornecem diretamente uma informação.

Outras precisam ser interpretadas.

Também existem pistas que só fazem sentido quando combinadas com outras.

Por isso, não é recomendado tentar resolver tudo imediatamente.

O jogador deve:

**observar → interpretar → relacionar → resolver → avançar**
